## Eng qisqa yo'l

<Steps>

1. **Kalitni oling** — `DAVIRIX_KEY` muhit o'zgaruvchisiga qo'ying.

2. **SDK'ni o'rnating:**

   ```bash
   pip install davirix
   ```

3. **Birinchi ijroni yuboring:**

   ```python
   from davirix import Davirix

   dx = Davirix(api_key=os.environ["DAVIRIX_KEY"])
   n = dx.run(agent_id="acme-support", tenant_id="acme-bank",
              input={"text": "Kartani bloklang, oxirgi 4 raqam 7731"})

   n.status      # "completed"  — model javob berdi
   n.verified    # ⚡ AMAL tasdiqlandimi
   ```

4. **Farqni tushuning** — `status` va `verified` bir xil emas.
   Buni tushunmasdan integratsiya qilish eng ko'p uchraydigan xato:
   [eng muhim qoida](/boshlash/eng-muhim-qoida/).

</Steps>

## Nima bilan boshqacha

| | Oddiy AI pipeline | Davirix |
|---|---|---|
| Tarmoq uzildi — amal bajarildimi? | ❓ bilmaydi | `UNKNOWN`, qayta yuborish **taqiq** |
| Qayta urinish → ikkita SMS? | ⚠ ha | 10 000 parallel → **aynan 1** |
| Model «yubordim» dedi | ✅ ishonadi | `ACKNOWLEDGED` ≠ `VERIFIED` |
| 2 yildan keyin: «nega bu qaror?» | ❌ iz yo'q | offline manifest, 1 bayt buzilsa aniqlanadi |

## Asosiy qoida

:::danger[Davirix tizim sotadi, agent emas]
1. Biznes operatsiyasi **bizning platformamizda** yashaydi — tashqi SaaS'da emas.
2. Tashqi tizimga ulanish ikki maqsadda: **kontragent** bilan ishlash (abadiy)
   yoki mijozni **ko'chirish** (so'nadi).
3. AI — alohida mahsulot emas, **tizimning xususiyati**.
4. Uchinchi tomon **domen yozadi** (ichimizda), konnektor emas (tashqarida).
:::

⚡ Shuning uchun biz begona CRM'da ish bajarmaymiz. Biz mijozni
**yonma-yon** ishlatib ko'rsatamiz, keyin u xohlasa ko'chadi — va o'sganda
**migratsiya bo'lmaydi**.
